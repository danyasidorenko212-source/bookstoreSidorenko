# Bookstore REST API

Навчальний backend-проєкт книгарні на Java 21 та Spring Boot 3.4.13. Дані зберігаються в пам'яті й заповнюються під час запуску застосунку.

## Запуск

Потрібні JDK 21 і Maven 3.9+.

```bash
mvn spring-boot:run
```

За замовчуванням сервер доступний на `http://localhost:8080`.

## Ендпоінти

- `GET /api/books` — перелік книжок у форматі карток.
- `GET /api/books/{id}` — докладна інформація про книжку; для невідомого id повертається HTTP 404.

Приклади запитів див. у [requests.md](requests.md).

## Структура

`domain` — модель предметної області; `repository` — контракт і сховище в пам'яті; `service` — бізнес-логіка; `web` — REST-контролер і DTO. Маппер відокремлює модель від HTTP-відповідей. Залежності передаються через конструктори.
